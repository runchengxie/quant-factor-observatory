# quant-factor-observatory

[中文 README](README.zh-CN.md)

[Open the live Observatory](https://runchengxie.github.io/quant-factor-observatory/)

The public research Observatory for browsing factor definitions, data quality, research status, and reviewed aggregate evidence.

This repository is a presentation and publication surface. It is not a factor calculation engine and contains no raw market or financial data, per-security signals, portfolio weights, private research code, or credentials. Private research produces reviewed and redacted static snapshots that satisfy the public publication contract.

## Site routes

- `/`: research overview and data context
- `/alpha810`: Alpha 810 aggregate evidence catalog and details
- `/factors`: unified factor catalog
- `/jumps`: jump-risk decomposition
- `/hermite`: distribution shape and state views
- `/fundamentals`: fundamentals and human-capital research catalog
- `/studies`: PB/ROE, R&D, and labor-cost studies with evidence boundaries

## Public data boundary

Public snapshots may contain:

- factor names, research families, and public definitions.
- economic intuition, research status, and data quality.
- redacted cross-sectional summaries, time-series examples, and aggregate attribution.
- point-in-time state, coverage, and missingness.

They must not contain:

- exact private operators, parameter windows, and portfolio rules.
- raw provider mappings and local file paths.
- complete per-security signals, portfolio weights, and execution details.
- private backtest code, raw data, or credentials.

## Local development

The site consumes reviewed public snapshots committed under `site/public/data/`:

`factor-snapshot.json` is a demonstration dataset with 3 tickers and 42 consecutive calendar dates, including non-trading days. Its legacy `trading_days` field is displayed as “sample dates.” Fundamental PIT data comes from the separate `fundamental-snapshot.json`; their date ranges, universes, and availability definitions should not be combined.

```bash
npm ci --prefix site
npm run dev --prefix site
```

Build:

```bash
npm run build --prefix site
```

Generate redacted results in the private research environment before replacing public snapshots. Run these checks before submitting:

```bash
python scripts/audit_public_release.py
python -m unittest discover -s tests -v
python scripts/audit_research_updates.py --check
```

Run these commands from the repository root. The review-baseline check compares the committed public projections with their recorded baseline; without `--owner-root`, private sources remain `not_checked`. Do not recapture the baseline merely to clear a failure. Review the changed evidence first.

The build runs the legacy evidence contract check, TypeScript project checking, and Vite. There is no separate configured lint command or coverage threshold. `npm audit --prefix site` checks dependency advisories separately; a passing public-release audit does not establish dependency security.

Browser checks use Chromium:

```bash
(cd site && npx playwright install chromium)
npm run test:e2e --prefix site
```

Each browser test invocation starts its own preview server on an available local port and stores its build, traces, and test output in a unique `observatory-playwright-*` directory under the system temporary directory (`TMPDIR` on Unix). Set `PLAYWRIGHT_PORT` to request a specific port; an occupied port fails rather than reusing another server.

Failed tests retain a Playwright trace, screenshot and error context in `test-results`; passing tests discard their trace and screenshot. Open a retained trace with `npx playwright show-trace <path-to-trace.zip>`. CI uploads failed browser diagnostics as `browser-failures-<commit>` for 14 days. Temporary artifacts are retained for inspection and can be removed after review.

Functional browser tests use fallback fonts and a local fixture for the external font stylesheet. They validate data, controls, localization, and layout without depending on font-CDN availability; they do not validate the live font service. Language actions, theme labels, and snapshot source labels use the locale catalog.

Alpha 810 snapshots are generated by [`money-trees`](https://github.com/runchengxie/money-trees). The current schema 1.2 snapshot covers 2016–2025. Alongside aggregate IC, RankIC, coverage, grouped returns, annual and CSI 300 regime summaries, uncertainty estimates, and family-wide multiple-testing diagnostics, it includes HAC lag-sensitivity and moving-block bootstrap intervals. It contains no per-security values, portfolio weights, or raw data paths. Historical point-in-time input availability and executable fills have not been established. See the [public contract](docs/alpha810-public-contract.md) and the provider's [MkDocs documentation](https://runchengxie.github.io/money-trees/) for details.

The site defaults to `en-US`, supports `zh-CN`, and preserves the selected locale in local storage when available. Unknown stored locales fall back to English. Snapshot validation errors use localized presentation while retaining HTTP status and schema field names. Changing locale does not change snapshot data or validation rules.

See the [public Alpha 810 contract](docs/alpha810-public-contract.md).

The study publication boundary is defined by the [English contract](docs/research-publication-contract.md) and its [Chinese structured explanation](docs/research-publication-contract.zh-CN.md). The public research manifest records provenance, language, and redaction boundaries.

## Relationship to full public studies

This site owns factor catalog organization, standardized factor studies, publication status, and reviewed projections under the publication contract. Independent market research projects and their project-specific methods remain in [`quant-market-research`](https://github.com/runchengxie/quant-market-research). A factor study may be presented here when it meets this repository's source identity and review requirements. Link to the authoritative method and evidence rather than copying complete source material. Private strategy evidence remains in its owner repository; only an explicitly reviewed and redacted projection may appear here.

## Human-capital and labor studies

The catalog includes experimental entries for labor-cost intensity, human-capital efficiency, labor-cost changes, income-versus-labor-cost divergence, and labor intensity versus investment state. These entries express research hypotheses and do not imply completed A-share predictive validation. Pages show when public evaluation is unavailable.

## Private research and public publication

```text
Private research engine
    ↓ run backtests, attribution, and robustness checks
Redacted public snapshot
    ↓ retain only fields allowed by the public contract
quant-factor-observatory
```

Historical commits may contain removed internal implementations. If historical visibility must change, create a clean public repository or perform an explicitly authorized history rewrite after preserving backups; an ordinary deletion does not remove Git history, forks, or existing clones.

Research navigation keeps `/studies` focused on searchable topic cards. Each topic carries its evidence basis, experiments, interpretation changes and expandable source review record. `/studies/evidence` provides the cross-topic matrix, while `/studies/compare` retains the registered quantitative comparisons. Human-facing review times use the selected locale and Asia/Shanghai time; original timestamps remain in source details.

## Distribution and jump exploration

The jump page compares all published observations as IVhat + RLJV + RSJV stacks, with absolute variance and RV-share scales. Its sortable table retains invalid and missing observations; charts exclude negative, unreconciled, or zero-denominator rows. Inspection opens the selected observation’s breakdown.

The Hermite page compares one indicator across example tickers over a selected date range. It aligns observations by calendar date, preserves gaps, and derives valid counts, missing counts, median, minimum, and maximum from the displayed series. An expandable table exposes the same daily values. These statistics describe indicator values, not the underlying return distribution. Separate published cross-sectional quantiles are not used in these summaries. The demo’s 42 dates include non-trading days.

### Evidence review dates

The study index and evidence summaries show the review date of the published evidence record, separately from data snapshot dates and automated source checks. `site/src/evidenceReviewRecords.json` is a small projection of the existing navigation records and historical-risk source metadata; missing review dates stay null. After updating these sources, run `python scripts/build_evidence_review_records.py`. The public-contract test checks the dates and source revisions against the cited assets.
