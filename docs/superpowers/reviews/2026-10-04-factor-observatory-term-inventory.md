## Shared definitions and checks

| Displayed term / field | Verified meaning and intended reader explanation | Pages / source |
| --- | --- | --- |
| Factor / factor family | A factor is a rule that assigns a value or order to stocks using one or more characteristics. A family groups related rules; it does not mean they have equal evidence. / 因子是按一个或多个特征给股票计算数值或排序的规则。因子族把相关规则归在一起，不代表其中证据同样充分。 | Overview, catalog, factor page; catalog and factor records |
| Factor score, high/low direction | The score is the output of the displayed rule. “Higher” only has the interpretation stated for that factor; a score is not itself a return. / 分数是该规则的计算结果。“高分”只按该因子注明的方向解释，分数本身不是收益。 | Factor explorer/detail; factor definitions |
| Coverage / valid observations | Valid observations divided by the observations expected under that metric's date/sample rules. It describes available data, not market-wide coverage or predictive quality. / 有效观测数相对该指标按日期和样本规则应有观测数的比例。它表示数据可用程度，不代表覆盖了全市场或预测质量。 | Factor catalog, fundamentals, Alpha 810; source snapshots |
| PIT / point-in-time availability | Information is assigned only from the date it was publicly available under the stated source rule. A historical observation alone does not prove every underlying revision or security-eligibility input is point-in-time correct. / 按注明的数据规则，只在信息当时已公开后使用。历史日期上的数值本身不能证明底层修订版本和股票资格都已通过点时核验。 | Overview, factors, fundamentals and studies; source and study notes |
| Cross-section / cross-sectional ranking | Compare or rank stocks against one another on the same observation date. It is different from comparing one stock through time. / 在同一观测日把股票彼此比较或排序；这不同于跟踪一只股票随时间的变化。 | Fundamentals, Alpha 810, study charts |
| P01 / P25 / P50 / P75 / P99 | Percentile cutoffs in the stated same-date sample: 1st, 25th, middle, 75th and 99th percentiles. They are standardized score units on the fundamentals chart, not currency. / 同一日期样本中的第 1、25、中位、75 和 99 百分位位置。基本面图显示的是标准化分数，不是金额。 | Fundamentals; `FundamentalsPage.tsx`, fundamental snapshot |
| Standardized proxy / score units | A transformed value put on a common scale for comparison. It is not the original accounting amount and is not money unless the page explicitly says so. / 为便于比较而转换到统一尺度的数值；它不是原始会计金额，除非页面明确注明，否则也不是货币。 | Fundamentals and factor detail; catalog units |
| TTM | Trailing twelve months: a rolling total over the latest twelve months. The page's note specifies whether reported cumulative fiscal-year values are differenced to form quarters. / 最近连续 12 个月的合计。页面会说明是否从财年累计披露值中拆出单季数再计算。 | Fundamentals; public catalog notes |
| Null / missing / unavailable | No value was published or the required observations are incomplete; it does not mean zero. Preserve each page's stated reason when known. / 没有发布数值或所需观测不完整，不等于数值为零；原因已知时按页面说明保留。 | All data-backed routes; snapshots and loader rules |
| IC / RankIC | Alpha 810's daily cross-sectional Pearson correlation between factor values and next-period returns is IC; RankIC uses Spearman correlation, comparing their ranks. Neither is a portfolio return. / Alpha 810 中，IC 是因子数值与下一期收益的日度截面 Pearson 相关；RankIC 使用 Spearman 相关，比较两边的名次。两者都不是组合收益。 | Alpha 810; `docs/alpha810-public-contract.md` |
| Mean IC / mean RankIC | The mean across dates with a valid daily correlation, not a pooled stock-level correlation. / 对有效日期的日度相关值求均值，不是把所有股票观测合并后算出的相关。 | Alpha 810 overview/factor detail; public contract |
| IR (Alpha 810) | Mean daily correlation divided by its population standard deviation across valid dates. This IR describes stability of a correlation statistic; it is not the portfolio information ratio or Sharpe ratio. / 有效日期内的日均相关值除以其总体标准差。这里衡量相关统计的稳定程度，不是组合信息比率，也不是夏普比率。 | Alpha 810 factor detail; public contract |
| Positive rate | Fraction of valid dates on which the daily IC or RankIC is above zero. The denominator is valid dates, not all stocks or all days in the calendar range. / 日度 IC 或 RankIC 大于零的有效日期占比；分母是有效日期，不是股票数，也不一定是区间内全部日历日期。 | Alpha 810 overview/detail; public contract |
| G1–G5 / grouped return | On each date, sort valid stocks into five groups from lowest to highest factor value; calculate each group's simple one-day mean return, then average those daily means across valid dates. These values are not compounded or net of costs. / 每个日期把有效股票按因子值从低到高分为五组，先计算各组当日简单平均收益，再对有效日期求平均；没有复利，也未扣交易成本。 | Alpha 810 factor detail; public contract |
| Top-minus-bottom spread | Highest-score group's average return minus lowest-score group's average return under the displayed grouping and period. It is not the return of a costed portfolio. / 按页面分组和期限，用最高分组平均收益减最低分组平均收益；它不是扣除成本后的组合收益。 | Alpha 810 factor detail and annual evidence |
| Return field `next_period_return` | One-trading-day research label based on the source's next-session close outcome; it does not establish an executable fill at that price. / 基于下一交易日收盘结果的一交易日研究标签；不能据此认定可以按该价格成交。 | Alpha 810 context strip and table; public contract |
| HAC / Newey–West / Bartlett lag | A standard-error adjustment that allows nearby daily observations to be related. The listed lag controls how many neighboring periods are considered; lag settings are sensitivity checks, not separate samples. / 允许相邻日度观测彼此相关的标准误调整。滞后阶数决定纳入多少相邻时段；不同阶数是敏感性检查，不代表不同样本。 | Alpha 810 inference panels; public contract |
| Standard error / confidence interval / p-value | Standard error summarizes estimate uncertainty; the interval gives a range under the stated method; p-value measures how unusual the result is under the test's null assumption. These do not correct every selection or data-timing bias. / 标准误概括估计的不确定性；区间按注明方法给出一段可能范围；p 值表示在检验的零假设下，观察结果有多不寻常。它们不能消除所有选样或数据时点偏差。 | Alpha 810 factor detail; snapshot contract |
| BY / BH adjusted q-value; FDR | BY and BH adjust p-values across the tested factor family; q is interpreted against the stated threshold. BY controls false discoveries under general dependence; BH is a sensitivity comparison with different assumptions. Neither proves future performance. / BY 和 BH 都会针对所检验的因子家族调整 p 值；q 值需结合注明阈值解读。BY 在一般依赖条件下控制假发现率；BH 是假设不同的敏感性对照。两者都不能证明未来表现。 | Alpha 810 multiple-testing panels; public contract |
| Moving-block bootstrap | Repeatedly resample consecutive 20-session blocks (2,000 repetitions in the published snapshot) to retain some nearby-date dependence and estimate a percentile interval for mean daily RankIC. Descriptive only; it does not correct factor searching. / 反复抽取连续 20 个交易日的区块（公开快照为 2,000 次），保留部分相邻日期关联，并为日均 RankIC 估计百分位区间。仅作描述，不能校正因子筛选造成的偏差。 | Alpha 810 sensitivity/factor detail; public contract |
| Regime / bull / bear | Uses the previous 252 CSI 300 daily returns compounded; positive cumulative return is labeled bull, otherwise bear. The current date's benchmark return is excluded. / 根据此前 252 个交易日的沪深 300 收益复合计算；累计收益为正标为 bull，否则为 bear，不纳入当前日期的基准收益。 | Alpha 810 regime slices; public contract |
| Realized variance (RV) | Sum of squared observed price changes over the stated interval. It measures accumulated movement; it is not annualized volatility. / 指定区间内观测价格变化的平方和，概括累计波动；它不是年化波动率。 | `/jumps`; source decomposition contract |
| IVhat / RJV / RLJV / RSJV | IVhat is the estimate assigned to gradual/continuous variation; RJV is the jump-variation component; RLJV and RSJV split jump variation into larger and smaller jumps. Keep `RV = IVhat + RJV` and `RJV = RLJV + RSJV` intact. / IVhat 是分配给连续、缓慢变化部分的估计；RJV 是跳跃变化部分；RLJV 与 RSJV 再把跳跃部分分为较大和较小跳跃。保留 `RV = IVhat + RJV` 和 `RJV = RLJV + RSJV`。 | `/jumps`; decomposition identity and public snapshot |
| Hermite h3 / h4, skewness / kurtosis | h3 and h4 are implementation-specific shape diagnostics. Their scales are unpublished, so h3's sign is not standard skewness and h4 is not a formal kurtosis test. / h3、h4 是依赖具体实现的分布形状诊断，尺度未公开；因此 h3 正负不能当作标准偏度，h4 也不是正式峰度检验。 | `/hermite`; `explorationCopy.ts` source limits |
| Evidence stage / status / decision | These labels describe what kind of work or evidence exists, not a performance grade. Explain the exact current status without mapping “completed” to “validated.” / 这些标签说明研究进行到哪一步或已有哪类证据，不是绩效评分；“已完成”不等于“已验证”。 | Study index/detail, hub, audit card; study records |
| Baseline / common sample / holdout | A baseline is the named comparison rule. A common sample uses the same eligible observations in both arms. A prospective holdout is future data kept separate until its labels mature and review gates pass. / 基线是明确列出的对照规则；共同样本表示两组使用相同合格观测；前瞻留出是暂不用于开发、待未来标签成熟并通过复核后才读取的数据。 | Study detail, comparison and navigation records |
| Within-formation Rank IC | The rank correlation between predicted and observed financial target values across stocks in a formation sample. It is not the RankIC between a stock factor and subsequent stock returns. / 在同一形成样本内，比较股票间预测值与实际财务目标值排序的相关性；它不是因子与之后股票收益之间的 RankIC。 | Forecast studies; `study-exploration/*.json` |
| MAE / transformed MAE / persistence | MAE is average absolute prediction error. When a target is transformed, MAE is in that target's transformed units, not currency. Persistence is the stated simple baseline that carries the latest/current state forward; its exact target and information date remain study-specific. / MAE 是预测误差绝对值的平均数。目标经变换时，单位也是对应的变换单位，不是货币。持续性基线把最近/当前状态延续到目标期；具体预测目标和信息日期以该研究定义为准。 | Forecast studies; `study-exploration/*.json` and source study |
| Annualized return / excess / information ratio | Annualized return expresses a multi-period result on a one-year scale, not a separate observed one-year result. Excess return is relative to the named comparator. Information ratio is distinct from Sharpe and uses the study's benchmark-relative return and variability definition. / 年化收益把多期结果换算为一年尺度，不代表单独观测到的一年收益。超额收益相对指定对照计算。信息比率与夏普不同，按该研究的基准相对收益和波动口径定义。 | Forecast/PB-ROE archived studies; source notes |
| 20/220-session horizon, cross-sections, forward label | `fwd20` and `fwd220` denote the recorded forward label horizons in trading sessions. `cross_sections` counts valid date-level stock comparisons; it is not the number of stocks. A label is a research outcome window, not an execution record. / `fwd20`、`fwd220` 指记录中的 20/220 交易日前瞻标签期限。`cross_sections` 是有效日期截面数，不是股票数；标签是研究结果区间，不是实际成交记录。 | R&D annual/detail; annual and study data contracts |
| Raw identifiers and provenance fields | `source_ref`, `source_revision`, `reviewed_at`, `run_id`, `source_vintage`, `market_data_as_of`, and hashes identify the cited record, version, review date, run, or data cutoff; retain them verbatim and explain their role nearby. They do not certify a source as correct by themselves. / `source_ref`、`source_revision`、`reviewed_at`、`run_id`、`source_vintage`、`market_data_as_of` 和哈希值分别标识来源记录、版本、复核日期、运行、数据版本或行情截止日；原样保留并说明用途。字段本身不能证明来源一定正确。 | Study source panels, audit card and annual page; public records |

## Unresolved-definition handling

| Displayed item | Known boundary | Required treatment |
| --- | --- | --- |
| h3/h4 exact calculations and scales | Private implementation is not published. | Keep the diagnostic labels, describe only the supported shape interpretation, and state that scale/standard-moment equivalence is unknown. |
| A source field whose unit, numerator, or availability timestamp is absent | A public identifier may be visible without a complete data contract. | Preserve the identifier; say the unit/definition/availability mapping is not documented in the public snapshot; do not infer it from values. |
| Study acronym or baseline without one common meaning | Several studies reuse labels such as IC, IR, current, or persistence for different outcomes. | Define at the study's point of use and name its target/sample; never reuse a broader definition that changes the comparison. |
